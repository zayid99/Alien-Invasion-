The files are the optimized copies published in the npm package `@netforge/asset-library-files` (see `public/assets/LICENSES/NOTICE-asset-sources.txt` for where each license was verified). The CC0 legal text is in `public/assets/LICENSES/CC0-1.0.txt`.

## Map data

World map shapes come from **Natural Earth** (public domain), via the `world-atlas` npm package (ISC license).

## Made in code

The flying saucer, gray aliens, farm animals (cows, sheep, pigs, chickens), houses, barns, silos, the mothership, Earth's shield pylons and HQ, and all the synthesized sound effects are built procedurally in `src/gfx/`.
